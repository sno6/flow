A freewriting tool that keeps you in the flow.

## Running locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — dev server with hot reload
- `npm run build` — production build to `dist/`
- `npm run check` — typecheck
- `npm run lint` — lint
